# Base de conhecimento

Os documentos desta pasta são exemplos públicos e autorais para desenvolvimento e avaliação do NexoOps.

Eles não foram copiados de uma empresa e não devem ser usados como procedimento operacional real.

## Critérios de escrita

- linguagem direta e fácil de consultar;
- uma decisão ou grupo de ações por seção;
- papéis genéricos em vez de nomes de áreas internas;
- sem metas, códigos, sistemas ou dados confidenciais;
- indicação explícita de ações proibidas e revisão humana;
- conteúdo que possa ser transformado em perguntas de avaliação.
